# Vendored fonts

Downloaded 2026-10-21 from Google Fonts CSS API and fonts.gstatic.com.
Noto Sans SC / JP: variable weights 400–600; Nunito: 700–800.
All unicode-range chunks supplied by the API are retained, including uncommon characters.
The browser loads only ranges needed by displayed text; there are no runtime CDN calls.
Original URLs, sizes and SHA-256 digests are recorded in manifest.json.
SIL OFL licenses accompany the font files.

CSS API families: `Noto+Sans+SC:wght@400..600`, `Noto+Sans+JP:wght@400..600`, `Nunito:wght@700..800`, with `display=swap`.
