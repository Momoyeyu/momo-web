# 004：thinking 开关配对实验（2026-10-22）

结论：这组日常角色互动中，thinking 没有稳定改善回答；建议保留开关，首版默认关闭，复杂任务是否获益需要另测。它不是模型总体能力排名，也不证明 thinking 普遍无用。

## 方法与评分

使用同一个 `deepseek-chat`、现有 soul、提示词和 Hiyori 动作目录；6 场景 × 开 / 关 × 2 次，共 24 次真实 FastAPI `/api/chat` 调用。每次使用独立临时数据库、相同配对上下文，交替模式先后并打乱场景，内置记忆工具真实执行。没有复制玩家对话或记忆。

运行前固定题目和规则；我（Codex）按匿名 A/B 的可见回复、ACT 与工具结果逐条主观评分，填写分数后才查看模式映射。每项 0–4 分：0 严重失败，1 明显问题，2 基本可用，3 良好，4 场景贴合；总分 16，等权。自然度项同时考虑冗长和角色语气。评分不是人类玩家盲评。

| 指标 | thinking 关 | thinking 开 |
| --- | ---: | ---: |
| 自然度 / 4 | 3.75 | 3.08 |
| 情境理解 / 4 | 3.75 | 3.67 |
| 指令与事实 / 4 | 3.92 | 3.50 |
| 表演适配 / 4 | 3.50 | 3.75 |
| 总分 / 16 | 14.92 | 14.00 |
| 后端首句延迟中位数 | 0.865 秒 | 1.742 秒 |
| 回合总耗时中位数 | 1.077 秒 | 1.853 秒 |
| 输出 token 合计（12 次，含思考） | 798 | 2,198 |

12 对中，关闭模式得分更高 8 对，开启更高 4 对。24 次均成功；4 次记忆工具试验均实际落库。开启模式首句中位延迟增加约 0.88 秒，输出 token 约为关闭的 2.75 倍（含 1,001 reasoning tokens，不能重复相加；这不是计费金额比）。

## 场景表现

| 场景（各两次均分） | 关 / 16 | 开 / 16 |
| --- | ---: | ---: |
| 欢迎与蛋糕 | 15.5 | 11.5 |
| 被夸奖 | 15.5 | 13.0 |
| 认真安慰 | 14.5 | 15.0 |
| 表达不满 | 14.0 | 14.0 |
| 上下文与短答约束 | 15.5 | 15.5 |
| 实际记忆工具 | 14.5 | 15.0 |

- **欢迎 / 夸奖**：关闭时更短、更像即时反应。开启的一次蛋糕回答加入了未提供的视觉细节，并暗示之后可以吃蛋糕；两次夸奖回答声称此前“想了很久”，缺少上下文依据，因此扣分。
- **安慰**：开启的一次回复很好地接住情绪，但另一条更长；关闭也有自然、留空间的回答，差异不稳定。
- **抗议**：两种都能表达边界、避免辱骂；开启有时写成较长的心理分析，角色的轻巧感减弱。
- **约束 / 工具**：两种都正确满足一句话顺序约束并真实记住偏好。开启的表演控制略丰富，但不等于文字更自然；记忆场景的小幅优势也不足以支持普遍结论。

## 范围与可复核材料

本实验贯穿 HTTP 入口、真实模型、ACT 解析、内置工具及落库，但使用 TestClient，不是 24 次浏览器自动化。首句时间在后端真实 sentence yield 处测量，避免 TestClient 缓冲误差；不包含浏览器绘制、网络传输、TTS 首包或语音播放。本实验不能评价实际动作动画与声音的丰富度。另行浏览器 E2E 已验证两种模式的真实模型回复、字幕 / backlog 无控制串泄漏、开关保存与设置交互。

样本仅 6 类常见场景、每种 2 次，未固定供应商采样种子；本次不同模式的表现也受随机性与服务负载影响，不能把约 0.92 分差当统计显著性。后台向量索引在实验中停用以减少 CPU 干扰，工具调用仍真实执行。
