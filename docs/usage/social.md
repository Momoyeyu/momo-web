# QQ 账号接入预览

入口在 **设置 → 拓展 → 插件 → QQ → 配置**。「拓展」内的 Live2D、MCP、插件各有独立页签，账号、权限与记录在 QQ 配置窗口中切换。

本版本接入的是你为 momo 准备的普通 QQ 个人账号。momo 使用独立登录会话，不索取平台密码，也不会改动你的日常客户端。平台网页的身份授权不能代替好友聊天权限。

**当前验证范围**：macOS arm64 已通过设置内扫码、原生账号恢复，以及真实好友私聊 → 模型回复 → QQ 平台确认发送的完整链路。它仍是开发预览，完整安装体验与跨机器资源分发尚未交付。资源与运行边界见 [受管 QQ 运行说明](../development/qq-managed-runtime.md)。

微信接入已归档，产品不再提供微信启用或登录入口。过去的渠道消息、发送结果与审计记录仍保留，不会因移除适配器而删除；旧微信待办不能恢复执行或转交其他插件。

## 配置与权限

在「账号」中点击「登录 QQ」。已有有效登录时会自动恢复；需要扫码时，用 momo 的手机 QQ 扫码并确认。二维码过期会自动更新，短暂超时会有限重试；本次登录长时间未完成时自动结束，之后仍可再次点击登录。已有账号绑定时，实际登录的 QQ 必须与该绑定一致；无需手动填写账号 ID。

登录后可以打开插件开关，允许 momo 按当前权限使用 QQ；未登录时不能打开。登录本身不会启动 momo 或自动启用插件，关闭插件也不会退出账号。权限和白名单修改后自动保存。

「退出登录」会停用 QQ 收发并清除本机登录凭据，下次需要扫码；聊天、记忆和已有权限设置保留，不会退出手机或其他客户端。关闭配置窗口或应用会保留登录。QQ 使用内置登录，无需配置 Docker、外部桥接地址或令牌。

权限页提供消息、账号能力和群聊三组配置。新能力默认关闭，开启某一项不会顺带授权其他项：

| 权限 | momo 可以做什么 |
| --- | --- |
| 收取私聊 / 回复文字 | 接收符合范围的消息，回复原会话；两项独立 |
| 主动私信 | 在本次激活的对话/活动中使用 QQ 工具主动发送；只允许已指定对象和时段，并受每小时上限、最短间隔限制 |
| 读取联系人 | 按授权范围读取联系人姓名、备注和稳定 QQ 号，支持分页 |
| 读取历史 | 读取所选 QQ 会话当前可取得的记录，支持分页；联系人、群和主人记忆分开 |
| 附件与媒体 | 发送玩家上传的文件/图片、下载当前获准会话的附件，并可在同一 QQ 会话回复附件；应用不向模型开放任意本机路径或网址 |
| 处理好友申请 | 查看待处理申请，在本机玩家授权的操作中接受或拒绝具体申请；对方的申请文本不能修改授权 |
| 群聊 | 只在单独指定的群范围内收发消息；空群名单不允许任何群 |
| 群管理 | 在指定群且 QQ 账号确有管理角色时，改群名、禁言/解禁成员、设置全体禁言或移除指定成员；不包括解散群或资金操作 |

主动权限是一项许可，不会仅因打开开关就向联系人群发。群内主动发言与主动附件同样受时段和频率约束；收到消息后的同会话回复不需要主动私信许可。模型工具只有在本轮权限允许时才出现，执行前仍会重新校验。返回 title、专注或叫停会撤销执行许可。

白名单通过输入 QQ 号后按回车或点击「添加」逐项登记，可直接移除条目；批量粘贴支持空格、逗号、分号或换行分隔。添加前会校验号码格式、重复和200条上限，整批不合法时不会修改已保存名单。用法、空名单含义与范围说明放在问号中，默认界面不展开长说明。

“仅与白名单聊天”可选。关闭时不按名单筛选，开启后只允许名单内联系人；开启但名单为空时不允许任何联系人。已有主人身份绑定会保留，不能仅凭相同昵称认定。其他好友的上下文与记忆独立，不能读到你的私人经历。群名单与联系人名单独立；联系人白名单开启时，群内发信人也必须在该名单中，不能借群聊绕过联系人限制。群聊使用独立受众，永不继承主人私聊记忆。

附件库在启用附件权限后出现。每份文件最多 8 MiB，支持图片、音频/视频文件、PDF 和文本等附件；只展示本 QQ 账号的资源。模型通过应用生成的资源标识选择文件，不需要玩家给路径；切换账号不会将旧文件带给新账号。音频/视频文件作为附件发送，不将它们冒充已播放的语音/视频通话。

## 在 chat 中使用

title 待机时不推理、自动回复或执行活动。Boot 进入 chat 后，消息才可在权限与时效允许的范围内按顺序处理；设置和记录页保持激活。

重启后，Boot 会在后台恢复已经启用且绑定过的 QQ 账号，不阻塞文字聊天，也不改变权限或白名单。会话失效时，到 QQ 账号设置重新登录；后台恢复不会覆盖你手动刷新的二维码，也不会重新打开已关闭的聊天。

可以说“去看看 QQ 消息”“先别玩手机，回来陪我聊两句”，或使用停止活动按钮。你的插话会先要求手机任务安全暂停，再由同一个大脑处理。实际消息已经发出时无法假装撤回。

“专注对话”暂停全部插件业务，账号连接和允许的收件可以保留。关闭专注不解除你单独叫停的活动，也不会恢复已撤销权限或结果未知的任务。

## 不确定的发送

连接断开或发送超时不等于确定失败。“记录”会保留原操作及平台实际返回的结果；momo 不会自动把未知结果当作成功或失败，也不会直接重发。

存在未决发送时，系统会自动停用 QQ 并安全收束执行。确认执行已经停止后，会结束等待、保留未知结果，不再阻塞后续本地使用；无法确认时继续保持暂停。需要继续使用 QQ 时，登录后打开插件即可，系统会重新核验账号与连接，不需要额外的恢复操作；旧命令不会因恢复、重连或 Boot 自动重发。
