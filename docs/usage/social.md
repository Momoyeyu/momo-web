# QQ 账号接入预览

入口在 **设置 → 拓展 → 插件 → QQ → 配置**。「拓展」内的 Live2D、MCP、插件各有独立页签，账号、权限与记录在 QQ 配置窗口中切换。

本版本接入的是你为 momo 准备的普通 QQ 个人账号。momo 使用独立登录会话，不索取平台密码，也不会改动你的日常客户端。平台网页的身份授权不能代替好友聊天权限。

**当前验证范围**：macOS arm64 的原生运行、设置内真实二维码以及隔离的界面/协议回归已通过；扫码后的真实账号收发正在联调。它仍是开发预览，完整安装体验与跨机器资源分发尚未交付。资源与运行边界见 [受管 QQ 运行说明](../development/qq-managed-runtime.md)。

微信接入已归档，产品不再提供微信启用或登录入口。过去的渠道消息、发送结果与审计记录仍保留，不会因移除适配器而删除；旧微信待办不能恢复执行或转交其他插件。

## 配置与权限

在「账号」中点击「扫码登录」，用 momo 的手机 QQ 扫码并确认。二维码过期时可刷新；关闭窗口保留登录，取消会使当前二维码失效。首次登录可以不填 momo 的账号 ID；已有绑定则必须与实际登录账号一致。

身份校验通过后，点击「保存并启用 QQ 聊天」保存当前设置并接入收发。登录本身不会启动 momo 或开放消息权限。登录会话管理可断开运行或确认忘记本地登录；忘记登录不会退出手机或其他客户端。QQ 使用内置登录，无需配置 Docker、外部桥接地址或令牌。

收取消息与回复文字可以分别关闭。其余尚未支持的权限会置灰，允许回复不包含主动联系他人、群管理或发朋友圈。

“仅与白名单聊天”可选。关闭时不按名单筛选，开启后只允许名单内联系人；开启但名单为空时不允许任何联系人。主人跨平台身份需通过一次性验证消息关联，不能仅凭相同昵称认定。其他好友的上下文与记忆独立，不能读到你的私人经历。

## 在 chat 中使用

title 待机时不推理、自动回复或执行活动。Boot 进入 chat 后，消息才可在权限与时效允许的范围内按顺序处理；设置和记录页保持激活。

可以说“去看看 QQ 消息”“先别玩手机，回来陪我聊两句”，或使用停止活动按钮。你的插话会先要求手机任务安全暂停，再由同一个大脑处理。实际消息已经发出时无法假装撤回。

“专注对话”暂停全部插件业务，账号连接和允许的收件可以保留。关闭专注不解除你单独叫停的活动，也不会恢复已撤销权限或结果未知的任务。

## 核对不确定的发送

连接断开或发送超时不等于确定失败。到“记录”查看原操作，核实后确认已发出或未发出；不要直接重发。

无法确认消息结果、但执行器已可靠停止时，可结束等待并暂停该插件，保留未知结果。之后明确恢复新消息会重新核验账号；旧未知命令不会因恢复、重连或 Boot 自动重发。
