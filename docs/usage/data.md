# 备份与迁移

配置、完整对话、记忆、参考音和自行导入的形象都属于你的本地数据。v3 只有一段持续关系，自动保存，不再提供平行存档槽。升级前建议先导出备份；不要直接复制仍在运行的 SQLite 文件，以免遗漏 WAL 中的新记录。

使用应用内的数据导出 / 导入入口，将后端一致性备份和浏览器 IndexedDB 中的模型 ZIP 一同放入带版本、文件清单与校验值的归档。导入前校验内容与路径，应用失败时恢复原现场。旧 Rust 版本的数据不自动当作新格式读取。

备份可能包含对话服务密钥和私人内容，只应保存在自己控制的位置，不上传到 issue、公共仓库或公开测试报告。应用日志和安装资源包不是用户数据备份。

正式桌面应用使用独立数据目录；浏览器开发版默认使用 `.workbuddy/dev-data/`，不覆盖现有体验档。旧存档槽只读保留，不拼接成重复对话；迁移也不能找回旧版本已经删除的文本。

恢复备份会替换当前关系数据，先暂停活动并撤销旧回合，成功后仍保持暂停；旧收发队列不会自动重放。新插件授权凭据默认不随备份导出，需要重新授权。卸载程序与主动删除用户数据是不同操作，迁移前先保留可恢复副本。
