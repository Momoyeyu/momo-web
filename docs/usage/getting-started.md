# 初次见面

本页说明 v3 Web 开发预览；已发行桌面版的安装说明见文末链接。第一次开始见面前，填写兼容 OpenAI 格式的对话服务地址、API Key 和准确模型名称，连接检查通过后才能进入对话。momo 会主动打招呼、询问称呼；称呼会成为可以修改的记忆，不想回答也可以继续聊天，之后启动不会重复第一次引导。

在设置的「模型」页填写对话服务地址、API Key 和模型，然后测试连接。思考模式默认关闭，支持的服务可以手动打开；思考过程不会出现在对白或被朗读。

语音识别和记忆检索由应用自带，无需额外配置或首次下载。可以直接打字，也可以开启麦克风说话。播放过程中使用发送位置的停止键或开口打断。

想让 momo 发声，可选接入推荐的 [TTS 服务](tts.md)，上传参考音频并填写对应文本；未配置语音不影响文字聊天。

更换形象、设置表情 / 动作及预览位于「拓展」中的形象配置。安装拓展时只启用你信任的工具；工具能力随你接入的拓展增长。

记忆可以在设置中查看、修改或删除。现在只有一段自动保存的持续关系，从标题进入同一个 momo；历史回顾支持向前翻阅。设置和历史页仍属于这次见面，回到标题才结束见面。跨安装迁移请先阅读 [备份与迁移](data.md)。

[下载 momo v0.2.0](https://github.com/Momoyeyu/momo/releases/tag/v0.2.0)：提供 macOS 14+ Apple Silicon 与 Windows x64 安装包，Windows 11 实机已验证。安装包未获开发者签名 / 公证，首次安装步骤与 SHA-256 见版本说明。Linux、手机 / 平板暂不提供。
