# 初次见面

本页说明 v3 Web 开发预览；已发行桌面版的安装说明见文末链接。首次启动先进入标题，跟随高亮引导打开设置，在「通用」确认界面语言，再进入「模型」填写兼容 OpenAI 格式的对话服务地址、API Key 和准确模型名称。对话语言在引导期间跟随界面语言。点击「测试」会真实检查模型和工具调用能力，通过并保存后返回标题。

点击“启动 / Boot”进入 chat，momo 才激活。初识时 momo 会询问称呼，告诉她一个喜欢的昵称即可；不要求真实姓名，尚未确认时会继续询问。昵称实际写入可编辑记忆后，按引导返回标题，结束初识，再次启动便可自由聊天。引导进度会保存，退出后不用重新配置已经确认的步骤；已有玩家不会强制重走首次引导。

在设置的「模型」页填写对话服务地址、API Key 和模型，然后测试连接。思考模式默认关闭，支持的服务可以手动打开；思考过程不会出现在对白或被朗读。

语音识别和记忆检索由应用自带，无需额外配置或首次下载。可以直接打字，也可以开启麦克风说话。播放过程中使用发送位置的停止键或开口打断。

想让 momo 发声，可选接入推荐的 [TTS 服务](tts.md)，上传参考音频并填写对应文本；未配置语音不影响文字聊天。

更换形象、设置表情 / 动作及预览位于「拓展」中的形象配置。安装拓展时只启用你信任的工具；工具能力随你接入的拓展增长。

记忆可以在设置中查看、修改或删除。现在只有一段自动保存的持续关系，从标题进入同一个 momo；历史回顾支持向前翻阅。设置和历史页保持这次激活，回到标题才收束执行并待机。账号连接不会自行激活 momo。跨安装迁移请先阅读 [备份与迁移](data.md)。
