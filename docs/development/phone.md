# 手机扩展点（011）

手机属于平台，App 不负责创建外壳。当前官方 QQ 同时提供图标、只读视图与真实消息投影；玩家通过对话让 momo 操作，不能在手机里冒用 momo 发送。

## 接入

- 前端 `src/phone/registry.tsx` 的 `registerPhoneApp({id, source, icon, render?})` 返回注销函数。图标与视图由对应 App 模块提供；没有 `render` 时显示待机桌面。官方示例为 `qqApp.tsx` 和 `QQPhoneView.tsx`。
- 后端 `services/phone.py` 的 `register_app(id, reader)` 返回注销函数。可信内置扩展的 reader 接收 `(peer, before)`，返回 App 描述、积压数及当前账号的只读消息分页。`snapshot` 聚合 App 与活动状态。当前动态 Cordis 插件不能注入任意浏览器代码；新增官方 App 需同时集成视图与投影。
- 注销时调用两侧 disposer。视图注册不会增加工具、执行许可或发送能力；业务继续经过 Cordis 与 Python 协调器。

## 显示与事实

- 关闭App会移除桌面入口、积压点与私有消息投影。活动优先采用较快的attention流；协调器另保留本次Boot的最近一次真实手机任务提示，避免短任务在两次轮询之间结束而漏展，提示不授予或重放操作。
- Boot 重置自动展示资格；收到消息只显示积压点，实际手机业务才自动展开。手动收起后本次 Boot 不再自动弹出；任务结束不自动收起。
- 专注不阻止玩家浏览，只暂停业务。浏览不消费队列、不清除积压点。
- QQ 入站来自 inbox；常规回复仅显示已确认可见的消息；主动文字仅在真实成功回执后显示。失败、结果未知显示为操作状态，绝不冒充已送达。附件与管理操作展示执行状态，不模拟不存在的原生 QQ 画面。
- 按 App、当前 QQ 身份和会话隔离；历史分页响应携带视图版本检查，切换时清理。离开 chat 停止轮询；同一 Boot 保留手机显隐偏好，浏览位置不持久化。
- Log 保留渠道与会话标记；QQ 内容不进入本地字幕或语音回放。

## 舞台操作栏

- chat 的工具按钮统一位于固定右侧竖轨，取景也使用全身 / 半身框选图标。图标表示点击后的取景，悬停显示本地化名称。
- 手机与对白抽屉切换不移动或重播工具栏动画；对白始终为侧轨留出水平安全间距。悬停名称与问号说明向轨道左侧展开。

## 验证

`backend/tests/test_phone.py` 覆盖账号隔离、回执、只读积压及第二 App 注册；前端 registry/projection 测试覆盖注销、自动显示、跨 App 身份和滚动消息合并。

运行开发服务后，在 frontend 执行 `node scripts/phone-smoke.mjs`，用独立无头浏览器与模拟 API 检查手机导航、长内容触底、手动收起、问号说明与较小 PC 窗口；不登录或发送真实 QQ 消息。

回归场景可执行 `node scripts/phone-smoke.mjs auto`、`short`、`disabled`、`disabled-live`，分别覆盖较慢消息快照、已结束短任务、关闭时空桌面与打开会话时停用App。

## 数字马赛克实体化

`effects/DigitalMaterialize.tsx` 接收 `visible`、`duration`、可选 `initialVisible` / `animate` / `onPresenceChange` 与任意 DOM children；与手机、App 注册、聊天状态无耦合。单份真实 DOM 通过 SVG `SourceGraphic` 参与过渡，不截屏、不复制交互树、不读取聊天像素。稳定时移除滤镜，恢复原生清晰文本和交互。presence在出现开始时通知true、消失完成时通知false；手机以此让对白保持收起，直到手机消解完才拉出，避免同时占用对白空间。

`digitalMosaic.ts` 是纯数值场：按固定种子生成每个20px格子的局部进度，混合细粒度噪声与弱空间关联；同一时刻各区域可处于透明、色块、低清、已清晰等不同阶段。RG编码采样位移（格内取样逐步20→10→5→2→原图），B编码显隐覆盖；另一纹理编码主题色中的短暂颜色误差、斜向高光与倒角反射。每格以不同相位及横/纵轴投影压缩至侧边再展开，形成翻转感，显隐覆盖与真实内容采样一起受该投影控制。位移、换色和覆盖都作用于真实本体，再裁入原始透明轮廓，没有外挂粒子层。采样分辨率与显示分辨率是不同概念：生成的是受限尺寸的控制图，不是缩小手机截图。

出现与消失共用同一进度场，快速反向保留种子与当前进度；完成后才允许下一次采用新种子。帧更新仅在过渡期间进行，跟随requestAnimationFrame，控制图上限96×256；格级参数预计算、像素缓冲复用，不在每帧重建画布，DOM尺寸按当前布局读取。减少动态效果直接切换最终状态；卸载取消帧与媒体查询监听。未启用WebGL或新增渲染依赖。后续复用应包裹需要解析的本体，勿将组件当粒子装饰层。

测试：`digitalMosaic.test.ts` 检查确定性、显隐端点、翻转投影与颜色变化；`e2e/30-digital-materialize.spec.ts` 检查双向中间态、反复反向、稳定后的滤镜释放及减少动态，并保存连续帧供视觉检查。

默认过渡440ms；同一Boot的手机桌面/App/会话与显隐状态在子页面往返时保留，`animate=false`让离场层直接保持最终态，不运行隐藏动画。角色横向构图跟随实体presence，在手机完全消失后才归中。

页面往返仅保留本机显隐与App/会话选择，不缓存私有消息正文；重新挂载后仍向后端核验当前账号与插件状态，避免在设置更换账号后展示旧账号投影。
