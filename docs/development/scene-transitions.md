# 场景转场

## Chat → Home：玻璃碎裂（2026-11-02 首版，待体验）

Home 点击立即在完整的真实画面上蔓延裂纹，同时准备临时纹理与 title 图像解码；准备好后正常返回 title、收束激活，真实 title 渲染在碎片背后。人物、房间、对白和可见手机都属于被切开的纹理。快照仅在内存中使用，完成、取消或被替代后释放，不持久化或上传。

`effects/GlassReturn.tsx` 用单个 Canvas 绘制约80块放射裂片；`lib/glassShatter.ts` 用共享顶点的冲击射线、错位横裂和少量三角尖片替代原蜂窝式 Voronoi。四角纳入边界射线，保证整个矩形覆盖完整。时序为 **640ms 裂开（480ms扩展＋160ms完整裂纹停留）→ 280ms分离 → 680ms掉落**，常规总长1600ms。裂开时画面完整；分离时明显翻面、拉开缝隙但不下落，随后才错峰重力加速。慢资源只让完整裂纹保持，不挤占后续阶段。

每块玻璃用投影侧面表现约4.5～7px厚度（1280基准宽），分离阶段已开始有正负方向的斜切/压缩/旋转。预先缓存的低饱和光谱带随翻面横向扫过表面，配近白高光与透青侧边，让变化在正常速度下可见。保留画面本色，不做整块彩色纸片、真3D或物理引擎。几何与材质在裂开时准备，纹理就绪后沿用同一随机种子，不在逐帧绘制里更新 React 状态。

`effects/captureStage.ts` 按需加载锁定的 html-to-image 1.11.13；进入 chat 后预热静态字体与 title 的剪影/标识，Home 悬停或聚焦也可预热。WebGL 在序列化对应画布前同任务重绘，不永久开启 preserveDrawingBuffer。快照分辨率上限为 1280 宽；准备最多等待 1400ms，title解码最多额外等待120ms，失败或超时沿用正常返回，不能锁住玩家。截图过滤裂纹层，避免裂纹烘焙两遍。减少动态时直接返回；后台隐藏、窗口缩放或路由改变会结束演出并清理资源。外部强制 hash 导航不等待或重放旧快照。

只给 chat 的 Home 按钮使用：title → chat 保持已验收的 ASCII/方格开场，settings / backlog 的往返保留 RoPE，手机独立显隐也保持 011 的效果。

验证：几何测试检查分区面积完整、随机种子可复现、下落与终点清空；`34-glass-return.spec.ts` 检查真实画面捕获、title 背层、手机打开、缩放、减少动态、快照失败与导航取消，并采集中间帧。浏览器使用隔离合成资料，不调用真实 QQ 或更改玩家配置。

快照依赖与接口说明参考 [html-to-image 官方源码](https://github.com/bubkoo/html-to-image/tree/v1.11.13/src)。本轮仅 Web，尚未验证桌面 WebView 的 SVG foreignObject 栅格化；桌面同步时需单独核验，失败路径始终可以回到 title。
