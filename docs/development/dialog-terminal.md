# 终端式对话框（2026-11-02，待体验）

聊天面板采用紫黑半透明底、6px小圆角与细边框；名称和真实状态内收为首行，正文与输入共用同轴提示符。Latin 使用系统等宽字体，中文/日语回落到现有界面字体。`ui/TerminalPrompt.tsx` 以SVG几何居中，避免CJK字形加入时改变提示符基线。

`DialogBox` 的 `typing` 来自现有响应状态，仅在响应过程中显示尾部块状光标；减少动态时停止闪烁。输入保留原生input、IME、选区、发送和停止行为，以聚焦时分隔线颜色提供反馈。透明度仍由既有设置控制，设置页预览共用同一个组件与外观。

侧轨、对话框收放、人物构图预留及转场时序保持原实现。`36-terminal-dialog.spec.ts` 覆盖中英日与三种PC尺寸、输入提示符中轴、长输出换行、手机收放和设置预览；截图使用隔离合成资料。
